# 🏫 인천공항고등학교 공항네컷 (GHHS 4-CUTS)

> 인천공항고등학교(GHHS) 축제 및 동아리 부스 전용 **9:16 세로형 터치 포토부스 키오스크**  
> EPSON L8180 포토 프린터 4x6 인화지 최적화 300 DPI 인생네컷 시스템

![인천공항고 공항네컷](assets/ghhs_emblem.png)

---

## 🌟 주요 기능 (Features)

- **🏫 인천공항고등학교 공식 아이덴티티**:
  - 공식 교표(Emblem) 탑재 및 학교 시그니처 컬러 테마
  - 공항 비행 스케줄 출발 안내 전광판 (FIDS)
  - 원터치 퀵 태그 (1학년, 2학년, 3학년, 동아리, 우정 영원히 등)
  - 터치 가상 키보드 내장 (키보드/마우스 없이 100% 터치 조작)
- **🎨 5가지 고품질 커스텀 프레임**:
  1. 🛫 **공항네컷 (비행기 & 인천대교)**: 비행기, 갈매기, 인천대교 일러스트 오버레이
  2. 🩵 **GHHS FILM (스카이 블루)**: "Create your own meaning" 파스텔 블루 감성
  3. 🌊 **GHHS mansion (윤슬 오션)**: 푸른 바다 물결과 윤슬 배경 2x2 프레임
  4. 🎞️ **GHism (화이트 필름)**: 지그재그(스태거드) 4컷 필름 릴 감성
  5. 🖤 **GHism (블랙 시크)**: 올블랙 시크 다크 룸 4컷 프레임
  6. 🎫 **항공 탑승권 (1+1 스트립)**: 2x6 트윈 스트립 규격
- **🖨️ EPSON L8180 포토 프린터 300 DPI 최적화**:
  - 4x6 인치 (1200 x 1800 px) 초고화질 출력
  - 독립 Iframe 인쇄 엔진을 통한 무결점 100% 꽉 찬 사진 출력
  - 무인 키오스크 자동 출력 모드 지원 (`--kiosk-printing`)
- **📸 스마트 웹캠 촬영**:
  - 고해상도 웹캠 연동 및 실시간 거울 모드 (좌우 반전)
  - 5초 / 8초 / 10초 카운트다운 및 음성 안내 ("셋, 둘, 하나")
  - 기계식 카메라 셔터 사운드 및 플래시 효과
  - 6종 감성 필터 (원본, 뽀샤시, 흑백, 빈티지, 노을, 쿨톤)

## 🚀 로컬 실행 방법 (Windows)

1. **일반 키오스크 모드 (인쇄 미리보기 확인)**:
   - `Start-공항네컷.bat` 더블클릭

2. **무인 자동인쇄 모드 (인쇄 창 없이 바로 출력)**:
   - `Start-공항네컷-무인자동인쇄.bat` 더블클릭

3. **웹 브라우저 접속**:
   - `http://localhost:8899/`
